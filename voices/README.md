# Voice Models Directory

Store voice model packages here. Each subfolder represents a voice model:

```text
voices/
└── example_voice/
    ├── model.onnx      # RVC exported ONNX model
    ├── index.faiss     # FAISS feature index (optional)
    ├── config.json     # Pitch shift, formant, metadata
    └── avatar.png      # Display icon in UI
```
